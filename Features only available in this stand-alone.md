What features does this full implementation of AutoISF offer which are not included in the plugin of mainstream AAPS?

_______________
FUNCTIONALITIES
* graphical representation of the history of AutoISF factors and iobTH
* graphical overlay of fitted parabola in the main glucose graph
* smoothing of the full 1-minute Libre dataset when coming directly from Juggluco
* calibration of data from Libre or G7 coming directly from Juggluco
* pausing SMB and AutoISF weights during a phase of recalibration
* using Automation States
* using automation triggers and actions specific to some AutoISF variables
* display Script Debug section on follower phone
* fixed step trigger automation

EASE OF USE
* readability of AutoISF tab
* quick access to exercise mode and displaying its status
* easy access to logfiles on the phone

* clean glucose records in database down to just last 7 days
* alternatively enter *half basal exercise target* in mmol/L
* automatic reminder to enable Physical Activity permission for phone step counter
